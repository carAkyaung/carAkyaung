# 🚗 CarAkyaung - ကားသတင်းစာ Website

ကားတွေ အကြောင်း သတင်းစာ၊ သုံးသပ်မှုများ၊ နည်းပညာ အကြူးချက်များ၊ နှင့် JDM အစီအရာများ ပါဝင်သည့် ခေတ်မီ website။

## ✨ Features

- 🏠 **Homepage** - ရူပ်ကွင်းကောင်းသည့် Hero Section နှင့် Featured Articles
- 📰 **ကားသတင်း** - နောက်ဆုံးပါ ကားသတင်းများ နှင့် အပ်ဒိတ်များ
- ⭐ **Reviews** - စိတ်ဖိုက်သည့် သုံးသပ်မှုများ နှင့် အဆင့်သတ်မှတ်မှုများ
- 🏁 **JDM** - ဂျပန်ကားများ နှင့် အလှတွေ အကြောင်း အစီအရာများ
- 🔧 **Tuning** - ကားတွေ Tuning၊ အင်္ဂါ မြှင့်တင်မှုများ
- 📖 **Buying Guide** - ကားကြည့်သည့် အကူအညီ နှင့် အကြူးချက်များ
- 📱 **Mobile Responsive** - အားလုံး စက်ပစ္စည်းတွင် စုံလင်သည့် ဒီဇိုင်း
- 🌙 **Dark Theme** - အင်္ဂလိပ်/အမှောင် Mode အလှလွင့်

## 🚀 စတင်မည်

### အစ ယူမှုများ

```bash
# Clone repository
git clone https://github.com/carAkyaung/carAkyaung.git
cd carAkyaung

# Dependencies တင်ပါ
npm install

# Development server အမှုတည်ခွင့် လုပ်ပါ
npm run dev
```

Browser တွင် [http://localhost:3000](http://localhost:3000) ကို ဖွင့်ပါ။

### Build for Production

```bash
npm run build
npm start
```

- **Next.js 14** - React framework

- **next-themes** - Dark mode support
